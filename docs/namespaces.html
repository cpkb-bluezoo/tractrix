Namespaces

Scanner is namespace-unaware; NamespaceFilter turns xmlns into events.

Two layers

  1. Scanner — always reports xmlns / xmlns:prefix as normal attributes.
  2. NamespaceFilter — optional wrapper that converts those attributes into XmlHandler::namespace(prefix, uri) and applies Namespace Constraints.

Wiring

use tractrix::{FeatureSet, NamespaceFilter, Parser, XmlHandler};

let mut app = MyHandler::default();
// namespace_prefixes = false → xmlns attrs are not also reported as attributes
let mut filter = NamespaceFilter::new(&mut app, false);
let features = FeatureSet::default(); // namespaces = true
let mut parser = Parser::new(&mut filter, &features, None, None, None)?;

The namespace event

  • Fires after start_element, before attributes (and before end_attributes).
  • Empty prefix means the default namespace (xmlns="…").
  • There is no matching end-namespace event; scope ends with end_element.
  • With namespace_prefixes = true, xmlns attributes are still reported in addition to namespace events.

Constants

XML_NAMESPACE_URI    // http://www.w3.org/XML/1998/namespace
XMLNS_NAMESPACE_URI  // http://www.w3.org/2000/xmlns/

Writer side

XmlWriter maintains its own prefix stack. Use write_namespace / write_default_namespace while a start tag is open. write_start_element_ns resolves a prefix from current bindings; write_start_element_prefixed does not emit xmlns automatically.
