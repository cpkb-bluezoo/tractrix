Security

Secure-by-default parsing: no XXE unless you opt in.

Defaults

  • External general and parameter entities are disabled.
  • access_external_dtd is empty — no protocol is allowed.
  • Entity expansion is capped at 64 000 expansions per document (billion-laughs mitigation).
  • If you pass None for the resolver, the scanner behaves as a refusing resolver for external content.

EntityResolver

TypeBehaviour
RefusingEntityResolver Always returns Ok(None) — no external loads
FileEntityResolver Loads from the filesystem when the protocol is allow-listed via access_external_dtd
Custom EntityResolver resolve / resolve_entity return Ok(Some(ResolvedEntity)), Ok(None), or Err

Opting in to external DTDs / entities

use tractrix::{FeatureSet, FileEntityResolver, Parser};

let mut features = FeatureSet::default();
features.external_general_entities = true;
features.external_parameter_entities = true;
features.access_external_dtd = "file".to_string();

let resolver = Box::new(FileEntityResolver {
    access_external_dtd: features.access_external_dtd.clone(),
});

let mut parser = Parser::new(
    &mut handler,
    &features,
    Some(resolver),
    None,
    Some("file:///path/to/doc.xml".into()),
)?;

Warning

Enabling external entities exposes your process to XXE-class attacks if you parse untrusted XML. Prefer leaving the defaults alone unless you fully control the document and the reachable file set.

Disallowing DOCTYPE

Set disallow_doctype_decl = true to reject any DTD declaration outright — useful for untrusted feeds that must be document-only.
