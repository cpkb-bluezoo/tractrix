Tractrix

Non-blocking push-model XML for Rust — parse bytes into events, or serialize events back to bytes.

Tractrix is a port of the Gonzalez streaming XML scanner and writer. These pages are the primary usage documentation: they define the contracts you must honour when implementing handlers or driving the writer. API detail also lives in rustdoc; start here for sequencing and lifetime rules.

Pipeline

bytes ──▶ ExternalEntityDecoder ──▶ Scanner ──▶ (NamespaceFilter?) ──▶ XmlHandler
           BOM, decl, charset,            WF + DTD                   xmlns → namespace
           line endings                   + validation               events

XmlWriter ──▶ bytes   (indent · charset/BOM · XML 1.1 · standalone DTD)
