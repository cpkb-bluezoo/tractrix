Features

Runtime FeatureSet — not Cargo feature flags.

Configure a FeatureSet before constructing Parser. Field defaults match Gonzalez’s secure SAX-like defaults. You can also use SAX feature URI strings via get_feature / set_feature.

Defaults

FieldDefaultDescription
namespacesonExpect namespace-aware pipeline (use with NamespaceFilter)
namespace_prefixesoffAlso report xmlns as attributes
validationoffDTD validation (models, attribute types, ID/IDREF, …)
external_general_entitiesoffLoad external general entities
external_parameter_entitiesoffLoad external parameter entities
disallow_doctype_decloffReject any DOCTYPE
access_external_dtd""Protocol allow-list ("file", "all", …)
entity_expansion_limit64000Max expansions per document
resolve_dtd_urisonResolve relative system IDs
string_interningonIntern element/attribute names

Example

use tractrix::FeatureSet;

let mut f = FeatureSet::default();
f.validation = true;
f.external_general_entities = true;
f.access_external_dtd = "file".to_string();

Mid-parse changes

Once parsing has started, changing namespaces or validation via set_feature is rejected. Prefer a fresh FeatureSet and Parser::new (or reset after reconfiguration as appropriate).

Feature URIs

Constants such as FEATURE_NAMESPACES, FEATURE_VALIDATION, FEATURE_EXTERNAL_GENERAL_ENTITIES, FEATURE_SECURE_PROCESSING, and properties PROPERTY_ACCESS_EXTERNAL_DTD / PROPERTY_ENTITY_EXPANSION_LIMIT are defined in the features module for SAX-style configuration.

FEATURE_SECURE_PROCESSING reports true when both external-entity features are off.
