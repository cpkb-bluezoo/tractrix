Parse in chunks

Feed a byte stream with receive(); close() when the peer finishes.

Tractrix never blocks on I/O. Your runtime reads bytes and calls receive. Call close exactly once at end of stream (idempotent thereafter). Use reset to reuse the parser for another document. 

use bytes::Bytes;
use tractrix::{FeatureSet, NamespaceFilter, Parser, XmlHandler};

struct App { /* … */ }
impl XmlHandler for App { /* override what you need */ }

fn feed(stream: impl Iterator<Item = Bytes>) -> tractrix::ParseResult<()> {
    let mut app = App { /* … */ };
    let mut filter = NamespaceFilter::new(&mut app, false);
    let features = FeatureSet::default();
    let mut parser = Parser::new(&mut filter, &features, None, None, None)?;

    for chunk in stream {
        parser.receive(chunk)?;
    }
    parser.close()?;
    Ok(())
}

Contract

Chunks may split tokens arbitrarily (<ro then ot/>). Streamed text may span receive calls — copy data you keep and honour save_buffers.

One-shot buffers: parser.parse_all(bytes) is receive + close.
