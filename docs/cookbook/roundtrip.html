Parse → write

Bridge XmlHandler events into XmlWriter for a streaming rewrite.

XmlWriter is not itself an XmlHandler. Implement a thin handler that forwards the events you care about. Keep an element name stack because end_element has no name, and buffer attribute values until end is true. 

use std::io;
use tractrix::{IndentConfig, ParseResult, XmlHandler, XmlWriter};

struct Rewrite<'a, W: io::Write> {
    w: &'a mut XmlWriter<W>,
    stack: Vec<String>,
    attr_name: Option<String>,
    attr_value: String,
}

impl<W: io::Write> XmlHandler for Rewrite<'_, W> {
    fn start_element(&mut self, q_name: &str) -> ParseResult<()> {
        self.w
            .write_start_element(q_name)
            .map_err(|e| tractrix::ParseError::new(e.to_string()))?;
        self.stack.push(q_name.to_string());
        Ok(())
    }

    fn start_attribute(
        &mut self,
        name: &str,
        _ty: &str,
        _declared: bool,
        _specified: bool,
    ) -> ParseResult<()> {
        self.attr_name = Some(name.to_string());
        self.attr_value.clear();
        Ok(())
    }

    fn attribute_value_content(&mut self, value: &str, end: bool) -> ParseResult<()> {
        self.attr_value.push_str(value);
        if end {
            if let Some(name) = self.attr_name.take() {
                self.w
                    .write_attribute(&name, &self.attr_value)
                    .map_err(|e| tractrix::ParseError::new(e.to_string()))?;
            }
        }
        Ok(())
    }

    fn characters(&mut self, text: &str, _ign: bool, _end: bool) -> ParseResult<()> {
        self.w
            .write_characters(text)
            .map_err(|e| tractrix::ParseError::new(e.to_string()))?;
        Ok(())
    }

    fn end_element(&mut self) -> ParseResult<()> {
        self.stack.pop();
        self.w
            .write_end_element()
            .map_err(|e| tractrix::ParseError::new(e.to_string()))?;
        Ok(())
    }
}

Namespaces & DTD

Forward namespace to write_namespace / write_default_namespace. Map DTD and lexical events to the corresponding writer methods if you need a full round-trip. Writer methods return io::Result; map failures into ParseError (as above) so the parser can abort cleanly.
