XmlWriter

Streaming serializer matching Gonzalez XMLWriter — indent, charset, namespaces, DTD.

XmlWriter<W: Write> buffers output and flushes to the sink when a threshold is reached (or on flush/close). It is not thread-safe. close flushes but does not close the underlying sink.

Construction

XmlWriter::new(sink)                          // 4 KiB buffer, UTF-8
XmlWriter::with_indent(sink, IndentConfig::spaces2())
XmlWriter::with_capacity(sink, capacity)
XmlWriter::new_vec()                          // in-memory Vec<u8>

Options (set before writing)

MethodDefaultEffect
set_indent_config(Option<IndentConfig>) None (compact) Pretty-print: newline + indent_count × depth chars before child elements / comments / PIs
set_charset(OutputCharset) / set_charset_name UTF-8 Output encoding; UTF-16/32 emit a BOM on first write
set_xml11(bool) false Escape CR, C1 controls, and U+2028 as character references
set_standalone(bool) false Omit PUBLIC/SYSTEM on DOCTYPE; inline external-subset decls into the internal subset

IndentConfig

IndentConfig::tabs()       // '\t' × 1
IndentConfig::spaces2()    // ' ' × 2
IndentConfig::spaces4()
IndentConfig::spaces(n)
IndentConfig::new(ch, n)?  // ch must be ' ' or '\t'; n > 0

OutputCharset

Utf8, Utf16Be, Utf16Le, Utf32Be, Utf32Le, Iso8859_1, UsAscii, or Encoding(&'static Encoding). Name aliases like "UTF-16" map to big-endian with BOM, matching Gonzalez.

Element write contract

  1. Open with write_start_element, write_start_element_ns, or write_start_element_prefixed.
  2. While the start tag is open: write_attribute*, write_namespace, write_default_namespace.
  3. Any content call (write_characters, nested start, comment, PI, …) closes the start tag with >.
  4. write_end_element with no content → self-closing />; otherwise </qName>.

Prefixed start does not emit xmlns

write_start_element_prefixed writes the qName only. Call write_namespace / write_default_namespace explicitly if a declaration is required. Redundant declarations (same prefix already bound to the same URI) are suppressed.

Content

MethodEscaping
write_characters&lt; &gt; &amp;; illegal C0 → decimal refs; XML 1.1 also C1 / U+2028
write_start_cdata / write_end_cdataNo escaping; rejects ]]> and illegal controls
write_commentSanitises -- and trailing -
write_processing_instruction*Sanitises ?> in data
write_entity_refEmits &name;
write_rawUnescaped (XSLT disable-output-escaping); may yield non-WF XML

DTD output

write_start_dtd(name, public_id, system_id)
write_element_decl / write_attribute_decl
write_internal_entity_decl / write_external_entity_decl
write_notation_decl / write_unparsed_entity_decl
start_external_subset() / end_external_subset()
write_end_dtd()
  • Normal mode: only internal-subset decls are written; external-subset decls between start_external_subset and end_external_subset are omitted.
  • Standalone mode: PUBLIC/SYSTEM omitted; all decls (including external subset) are inlined.
  • The internal subset bracket [ opens lazily on the first declaration.

Namespace lookups

get_prefix, get_namespace_uri, get_all_namespace_bindings. The implicit xml ↔ http://www.w3.org/XML/1998/namespace binding is recognised but not listed in get_all_namespace_bindings.

Lifecycle

w.flush()?;   // close pending start tag if needed, send buffer
w.close()?;   // same as flush; does not close the sink
let sink = w.into_inner();
